| № | До запуска: прогноз | После запуска: результат | Объяснение |

## Организация кода

- `task-service.js` — 9 прикладных функций ПР2. Не работает с DOM.
- `task-selectors.js` — функция `getVisibleTasks(tasks, filter)` для отбора по фильтру.
- `task-view.js` — `createTaskElement`, `renderTaskList`, `renderSummary`, `renderEmptyState`. Создаёт и обновляет DOM.
- `main.js` — хранит `currentTasks` и `currentFilter`. Подписывает обработчики на контейнеры один раз. В `renderApp` вычисляет видимую выборку.

Сводка считается через `getTaskStats(currentTasks)` в `task-view.js`, а не по количеству карточек в DOM.

* Кнопки «Выполнена» и «Удалить» на каждой карточке реагируют на клики, в том числе клик по вложенному `span.action-label`.

## Отладка и клавиатура

**Точка останова:** в `main.js` в функции `handleTaskListClick` на строке вычисления `id`.

Значения при отладке:

- `event.target` — `<span class="action-label">`
- `event.currentTarget` — `<ul id="task-list">`
- `dataset.taskId` — строка `"4"`
- числовой `id` — `4`
- действие — `"toggle"` или `"delete"`
- результат сервиса — `{ ok: true, tasks: [...] }`

**Клавиатура:** кнопки доступны через Tab. Enter и Space вызывают действие. После изменения статуса фокус возвращается на ту же кнопку. При удалении последней задачи фокус переносится на активный фильтр.

**Отказ:** при отсутствующем id (например, 777) выводится сообщение, массив не меняется. Некорректный id (например, `4abc`) игнорируется.

## Вывод

В ходе работы был реализован браузерный интерфейс для задач из ПР2. Освоены создание DOM-элементов, обновление представления после изменения состояния, делегирование событий и работа с `dataset`. Интерфейс использует те же 9 функций из `task-service.js`, что и ПР2 — новая бизнес-логика не писалась.

Ключевое различие: **изменение данных** происходит через сервисные функции и приводит к новому массиву, а **изменение DOM** — это лишь отображение этого массива. DOM полностью перерисовывается при каждом изменении, поэтому интерфейс всегда соответствует актуальному состоянию данных.
