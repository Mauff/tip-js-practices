## 8. Дополнительное задание (Вариант А. Данные поступают строками)
**Файл:** `js/progress-input.js`

**Почему недостаточно просто вызвать Number() и проверить результат на отрицательность?**
Функция `Number()` преобразует пустую строку и строку из пробелов в `0`, что может привести к ложному срабатыванию. Также `Number()` возвращает `NaN` для текстовых строк, и простая проверка `< 0` не отловит `NaN`. Кроме того, `Number()` не проверяет, является ли число целым. Поэтому нужно сначала проверить тип (строка), убрать пробелы через `trim()`, проверить на пустоту, и только потом проверять на `NaN`, целочисленность и диапазон.

**Результаты проверок:**
| Ввод (totalTasks) | Ввод (completedTasks) | Результат |
|---|---|---|
| "7" | "2" | Всего задач: 7, Выполнено: 2, Осталось: 5, Прогресс: 28.6%, Статус: В работе |
| " 7 " | " 2 " | Всего задач: 7, Выполнено: 2, Осталось: 5, Прогресс: 28.6%, Статус: В работе |
| "" | "2" | Ошибка: Общее количество задач не может быть пустым. |
| "abc" | "2" | Ошибка: Общее количество задач должно быть целым числом. |
| "2.5" | "2" | Ошибка: Общее количество задач должно быть целым числом. |
| "Infinity" | "2" | Ошибка: Общее количество задач должно быть целым числом. |
| null | "2" | Ошибка: Общее количество задач должно быть строкой. |
| undefined | "2" | Ошибка: Общее количество задач должно быть строкой. |
