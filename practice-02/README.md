## Задание 1. Функции, возвращаемые значения и ссылки

| № | Прогноз до запуска | Фактический результат | Причина |
|---|---|---|---|
| 1 | 5; "23" | 5; "23" | JS не преобразует типы: `2+3=5`, `"2"+3="23"`. |
| 2 | undefined | 16 (после исправления) | В исходном коде не было `return`, функция возвращала `undefined`. После добавления `return` возвращает `16`. |
| 3 | true; true | true; true | `alias` и `original` — ссылки на один объект. Изменение через `alias` видно через `original`. |
| 4 | "Изменённая книга"; false; true | "Изменённая книга"; false; true | `[...books]` создаёт новый массив, но объекты внутри остаются теми же (поверхностное копирование). |
| 5 | true; false | true; false | `{ ...oldBook, available: true }` создаёт новый объект. Свойство перезаписано, оригинал не изменён. |
| 6 | "Без названия"; "Без названия"; null; "" | "Без названия"; "Без названия"; null; "" | Параметр по умолчанию срабатывает только для `undefined`. Для `null` и `""` значение не заменяется. |
